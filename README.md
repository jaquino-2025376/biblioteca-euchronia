#  Librería Euchronia

> Una innovadora librería digital abierta a todo público.

##  Descripción

**Librería Euchronia** es una plataforma web diseñada para facilitar la administración y consulta de una amplia colección de libros mediante una interfaz moderna e intuitiva.

El sistema permitirá gestionar usuarios, libros, autores, categorías, editoriales, préstamos, reservas, reseñas y multas, proporcionando una experiencia eficiente tanto para los administradores como para los lectores.

El objetivo principal es promover el acceso a la información y la cultura mediante herramientas digitales que optimicen la gestión bibliotecaria.

---

#  Objetivo General

Desarrollar un sistema web de gestión bibliotecaria que permita administrar eficientemente el catálogo de libros, los préstamos, reservas y reseñas de los usuarios, garantizando un acceso rápido, seguro y organizado a la información.

---

#  Objetivos Específicos

- Gestionar el registro de usuarios y sus respectivos roles.
- Administrar el catálogo de libros, autores, categorías y editoriales.
- Controlar préstamos y devoluciones.
- Gestionar reservas de libros no disponibles.
- Registrar reseñas y calificaciones realizadas por los usuarios.
- Generar consultas e informes sobre disponibilidad, préstamos y popularidad de libros.
- Mantener la integridad de los datos mediante procedimientos almacenados, vistas y triggers.
